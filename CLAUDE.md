# CLAUDE.md

## Règles de code

- Écrire du code facile à lire et explicite, plutôt que compact.
- N'optimiser que si des problèmes de performance sont rapportés.
- Ne pas deviner, ne pas anticiper. Implémenter seulement ce qui est demandé, sans aller plus loin, à moins que ce soit demandé explicitement.
- N'ajouter des commentaires que si le code n'est pas explicite, ou s'il ne dit pas explicitement pourquoi il est là, ou pourquoi il est fait d'une manière qui peut sembler étrange.
- Les descriptions de variables ou d'attributs ne disent que ce que leur nom ne dit pas.
- Coder en français, à l'exception des termes techniques. Ne jamais traduire ni reformuler les termes des règles métier.
